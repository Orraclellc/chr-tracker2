RFID Keychain Management

📱 About RFID Keychains

RFID keychains provide secure, anonymous identification for participants. Each keychain contains only the participant's random ID number - no personal information is visible or stored on the tag.

Benefits of RFID Keychains:

  • ✅ Privacy Protection: No visible personal information
  • ✅ Durable: Waterproof, washable, long-lasting
  • ✅ Fast Check-In: Just tap to pull up participant record
  • ✅ Hard to Lose: Attaches to keys, bag, or belt loop
  • ✅ Anonymous: Random ID numbers protect identity

Write RFID Keychain for Existing Participant

⚠️ Before Programming:
  1. Make sure you have a blank NTAG215 NFC tag
  2. Write the participant's ID on the physical tag with permanent marker
  3. Have the tag ready to hold near the top of the iPad

Troubleshooting

Tag won't write
  • Make sure the tag is completely blank
  • Try using a different NTAG215 tag
  • Hold the tag steady near the top of the iPad for 3-5 seconds
  • Check that NFC is enabled in iPad Settings
Tag won't read
  • Make sure you're holding it close enough to the iPad
  • Check if the tag is damaged or demagnetized
  • Try cleaning the tag surface
  • Issue a replacement tag if needed
Lost keychain
  • Look up participant by name in the system
  • Write a new keychain with the same participant ID
  • Mark the old keychain as "lost" in notes
  • Consider keeping 10-15 spare programmed tags for quick replacement
