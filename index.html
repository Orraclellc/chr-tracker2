RFID Keychain Management

📱 About RFID Keychains

Each keychain contains only the participant's random ID — no personal information stored on the tag.

Benefits of RFID Keychains:

  • ✅ Privacy Protection: No visible personal information
  • ✅ Durable: Waterproof, washable, long-lasting
  • ✅ Fast Check-In: Tap to pull up full Participant Hub
  • ✅ Hard to Lose: Attaches to keys, bag, or belt loop
  • ✅ Anonymous: Random ID numbers protect identity

Program RFID Keychain for Participant

⚠️ Before Programming:
  1. Have a blank NTAG215 NFC tag ready
  2. Write the participant's ID on the physical tag with permanent marker
  3. Hold tag near the top of the iPad when prompted

RFID Status Overview

Troubleshooting

Tag won't write
  • Make sure the tag is completely blank
  • Try a different NTAG215 tag
  • Hold steady near top of iPad for 3-5 seconds
  • Check NFC is enabled in iPad Settings
Tag won't read
  • Hold closer to the iPad
  • Check if tag is damaged
  • Try cleaning the tag surface
  • Issue a replacement if needed
Lost keychain
  • Look up participant by name in Participant Hub
  • Program a new keychain with the same participant ID
  • Keep 10-15 spare blank tags for quick replacement
